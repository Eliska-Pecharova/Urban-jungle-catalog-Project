# 🌿 Urban Jungle Catalog Project

Interactive plant catalog with real-time search and filtering. 
The project demonstrates working with an external API, data manipulation, and creating a modern user interface.

---

## 🚀 Features
- Search for plants by name
- Dynamic filtering by category
- Responsive design for mobile and desktop
- Modern UI built on React

---

## 🛠 Technologies used
- React
- HTML5
- CSS3
- JavaScript
